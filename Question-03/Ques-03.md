## Exercise 3: The "Traffic Light" (Conditionals)

### Goal
Use `if`, `else if`, and `else` logic.

### Instructions
- Create a variable named `lightColor` and set it to `"red"`, `"yellow"`, or `"green"`. [web:2]

### Task
Write an `if/else` statement: 
- If the color is `"green"`, log: `"Go!"` 
- If the color is `"yellow"`, log: `"Slow down!"` 
- If the color is `"red"`, log: `"Stop!"` 
- For any other color, log: `"Traffic light is broken."`
