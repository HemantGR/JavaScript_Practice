## Exercise 2: The "Tip Calculator" (Operators)

### Goal
Use arithmetic operators to calculate values.

### Instructions
- Create a variable `foodPrice` and set it to `100`.
- Create a variable `taxRate` and set it to `0.05` (5%).
- Create a variable `tipRate` and set it to `0.10` (10%).

### Tasks
- Calculate the `totalPrice` by adding food price + tax + tip.
- Log the result.

### Bonus
- Use the Modulus operator (`%`) to check if the `totalPrice` is an even or odd number.  
  Hint: If `totalPrice % 2` equals `0`, it is even.
