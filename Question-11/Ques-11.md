## Exercise 11: The "Multiplication Table" (For Loop)

### Goal
Use a loop to generate a math table.

### Instructions
- Create a variable `number` and set it to `5`.

### Task
- Write a `for` loop that runs from `1` to `10`.
- Inside the loop, multiply `number` by the current loop counter (`i`).
- Log the result in this format: `"5 x 1 = 5"`, `"5 x 2 = 10"`, etc.
- Hint: You can use string concatenation (`"5 x " + i + " = " + result`) or just print the result for now.
