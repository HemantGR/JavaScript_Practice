## Exercise 5: The "Odd Number Hunter" (Loops)

### Goal
Use a loop to iterate and filter numbers.

### Task
- Write a `for` loop that runs from `1` to `20`. 
- Inside the loop, use an `if` statement to check if the current number is **odd**.  
  Hint: A number is odd if `number % 2 !== 0`.
- Only `console.log` the odd numbers.
