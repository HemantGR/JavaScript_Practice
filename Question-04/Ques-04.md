## Exercise 4: The "Function Machine" (Functions)

### Goal
Write a reusable function with parameters and return values.

### Tasks
- Write a function named `calculateArea` that takes two parameters: `length` and `width`.
- Inside the function, multiply `length` by `width`.
- Return the result (do not console log inside the function).
- Call the function with values `10` and `5`, save the result in a variable named `myArea`, and log `myArea`.
