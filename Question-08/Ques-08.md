## Exercise 8: The "Temperature Converter" (Functions)

### Goal
Create a utility function that performs math and returns a value.

### Tasks
- Write a function named `toCelsius` that accepts one parameter: `fahrenheit`.
- Inside the function, apply the formula: `(fahrenheit - 32) * 5 / 9`.
- Return the calculated Celsius value.
- Call the function with the value `100`.
- Store the result in a variable named `tempInC`.
- Log a message: `"100F is equal to [tempInC]C"`.
