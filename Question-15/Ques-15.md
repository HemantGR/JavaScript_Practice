## Exercise 15: The "Function Relay" (Functions calling Functions)

### Goal
Understand that functions can call other functions.

### Tasks
- Write a function `double(num)` that returns the number multiplied by `2`.
- Write a function `square(num)` that returns the number multiplied by itself.

### Chain the logic
- Create a variable `startingNumber = 5`.
- First, calculate the double of `startingNumber` and store it in a variable.
- Next, find the square of that result.
- Log the final answer.

### Hint
Double of `5` is `10`. Square of `10` should be `100`.
