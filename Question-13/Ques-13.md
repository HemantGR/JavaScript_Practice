## Exercise 13: The "Money Saver" (Accumulator Loop)

### Goal
Use a loop to add numbers together (the "Accumulator Pattern"). [web:1]

### Setup
- Create a variable named `bankBalance` and set it to `0`.

### Task
- Write a `for` loop that simulates saving `$10` every day for `7` days.
- Loop from `1` to `7`.
- Inside the loop:
  - Add `10` to `bankBalance`.
  - Log: `"Day [i]: Balance is now $[bankBalance]"`.
- After the loop ends, log: `"Total savings: $[bankBalance]"`.
