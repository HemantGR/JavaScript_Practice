## Exercise 14: The "Exam Pass/Fail" (Ternary Operator)

### Goal
Use the Ternary Operator (`? :`), which is a shorthand for `if/else`.

### Setup
- Create a variable named `myScore` and set it to `55`.
- Create a constant named `passingScore` and set it to `60`.

### Task
- Create a new variable named `result`.
- Use a ternary operator to check: Is `myScore` greater than or equal to `passingScore`?
  - If `true`, assign the string `"Passed"`.
  - If `false`, assign the string `"Failed"`.
- Log the result.
