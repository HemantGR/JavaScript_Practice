## Exercise 10: The "Countdown Blastoff" (While Loop)

### Goal
Practice the `while` loop syntax and decrementing (counting down).

### Instructions
- Create a variable `count` and set it to `10`.

### Task
- Write a `while` loop that runs as long as `count` is greater than `0`.
- Inside the loop:
  - Log the current value of `count`.
  - Decrease `count` by `1` (`count--`).
- After the loop finishes (outside the curly braces), log `"Blastoff!"`.
