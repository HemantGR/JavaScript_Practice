## Exercise 12: The "Day Translator" (Switch Statement)

### Goal
Learn to use the `switch` statement, which is cleaner than many `else if` blocks for exact matches.

### Instructions
- Create a variable named `dayNumber` and assign it a value between `1` and `7`.

### Task
Write a `switch` statement that checks `dayNumber`:
- Case `1`: Log `"Monday"`
- Case `2`: Log `"Tuesday"`
- Case `3`: Log `"Wednesday"`
- Case `4`: Log `"Thursday"`
- Case `5`: Log `"Friday"`
- Case `6`: Log `"Saturday"`
- Case `7`: Log `"Sunday"`
- Default: Log `"Invalid Day"` (if the number is not `1` to `7`)

### Note
Don’t forget to add a `break;` after each case.
